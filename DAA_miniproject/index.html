ALGORITHM SNAPSHOT

How Bellman–Ford finds your best route

It grows reliable route costs from your starting city, checks every connection, and remembers which city led to each improvement.

Works with negative edges
  1. 01

    Start with what is known

    Set the source distance to 0. Every other city starts at ∞, meaning no route has been found yet.

  2. 02

    Try each connection

    For a directed edge u → v, add its cost to the best known distance to u to get a candidate for v.

  3. 03

    Keep a cheaper result

    If the candidate is lower, update v's distance and set its previous city to u. Otherwise, keep the current value.

  4. 04

    Check and rebuild

    After up to V − 1 passes, check for a reachable negative cycle. If none exists, follow previous-city links to rebuild the route.

THE RELAXATION RULE

Does this connection improve the route?

distance[u]+weight(u, v)<distance[v]

If true, save the candidate as the new distance to v and remember u as its predecessor.

↳ Each improvement is visible in the live table and graph above.
↗

Why Bellman–Ford?

It revisits edges across multiple passes, so it can handle negative edge weights. A reachable negative cycle means costs can keep decreasing, so a finite shortest route does not exist.
